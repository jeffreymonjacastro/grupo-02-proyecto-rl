\section{Algoritmo de Aprendizaje por Refuerzo}
Describir el algoritmo implementado (ej. Monte Carlo Control On-Policy First-Visit, Q-Learning, SARSA para P1; o DQN / PPO para P2):
\begin{itemize}
    \item Mecanismo de actualización de la función valor $Q(s, a)$ o gradiente de política.
    \item Política de exploración: Comparación entre $\varepsilon$-greedy fijo y $\varepsilon$-greedy con decaimiento ($\varepsilon_t = \max(\varepsilon_{min}, \varepsilon_0 \cdot d^t)$).
    \item Hiperparámetros de entrenamiento (tasa de aprendizaje $\alpha$, tasa de exploración $\varepsilon$, número de episodios).
\end{itemize}
